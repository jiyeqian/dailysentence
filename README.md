# 每日一句 · 海报生成器

把 [欧路词典「英语每日一句」](https://dict.eudic.net/home/dailysentence) 的当日内容，
和乐词 App 的「个人信息卡片」模板合成为一张竖版手机海报
（标准版 **1080 × 1920**，需要时自动加高）。

一句话概括：**打开网页 → 自动抓取今日金句 → 一键生成可发朋友圈的打卡长图**。

## 特性

**抓取**

- 中英文句子、关键词、音标（英式 / 美式双音标）、词性释义、例句、出处
- 音标先归一化再排版：剥掉数据源自带的外层斜杠 / 方括号，统一印成
  `英 /dɪˈsiːv/　美 /dɪˈsiːv/`（单音标不加语言标签），不会出现双份斜杠
- 网页「每日一句」卡片左上角的配图（`static.esdict.cn/MediaPool/daymonthimg/…`，每天轮换）
- 真人发音地址（正常 / 慢速，可试听）
- 去标签时区分内外联：`<span>`/`<a>`/`<b>` 这类内联标签直接删掉、**不补空格**，
  只有 `</p>`/`<br>` 这类换行标签才换成一个空格 —— 上游会给关键词套高亮标签，
  一律换成空格会在中文里印出「我对他所说的感到 失望 。」这种多余空白

**上游缺内容时的兜底（2026-09-19 起）**

欧路偶尔会在「解析」区块整段漏发（只剩一段 CSS），此时页面**没有关键词、没有释义、没有例句**。
以前的做法是把句子里最长的词当关键词，猜出 `ourselves` 这种结果，再挂一张空卡片 —— 比不显示更误导。
现在的做法：

- **不猜词**：从英文句子按「闭类词黑名单 + 词频 + 词长」打分，给出 Top 3 候选关键词，默认选第一个
- **查词典补全**：拿候选词去 `dict.eudic.net/dicts/en/<word>` 取音标 / 释义 / 双语例句；
  查到「过去式 / 复数」这类词条时自动回查原形（`deceived` → `deceive`）
- **卡片圆标**：关键词 / 释义不是上游今天给的内容时，单词卡片**右下角**有一个很轻的加圈单字
  —— `补`（释义来自词典补全）或 `选`（只是自动选词，没查到释义）
- **改词自动重查**：在「文案」里改关键词，稍停一下就会自动重查词典并换掉音标 / 释义 / 例句，
  不会留下上一个词的内容；若你自己手写过释义，则不覆盖（只清掉属于旧词的音标与例句）
- **该藏就藏**：连候选都没有时**不画单词卡片**，版面自动收紧，只留句子与信息卡
- **可人工切换**：页面多出一块「关键词补全」，点其它候选即可重新查词回填
- 上游正常出数据的日子，以上逻辑完全不触发，也不会多发一个请求

> 词典页会把释义里随机的汉字换成小图（`<img class="dictimgtoword">`），单次抓取常常缺字。
> 所以这里用「多次抓取 + 逐位合并」把缺字补回来；再叠加长连接复用与串行节流，
> 因为上游在高频请求下会 302 到登录页。
>
> 有一小部分替换是**按字固定**的（图名就是那个字的指纹，整页同一个字永远缺），
> 重试再多也补不回来。这类残留缺字**不再硬删**：含缺字的义项整条不显示、
> 含缺字的例句整条丢掉 —— 宁可少一条，也不在海报上印「寂的」这种残词。
> 义项被剔完就当作「没查到」，退回只放关键词。

**合成**（标准版，默认）

- 版面**三段式**，从上到下：**顶部图片区**（固定 648px 高，默认铺满裁切）→
  **中部句子区**（日期胶囊靠右，英文 + 中文 + 出处作为一个整体居中）→
  **个人信息卡**（距左 / 右 / 底三边等距 48px）
- 画布**恒 1080×1920**，不自动拉长；句子靠**改字号**适配：自动放大/缩小到「尽量铺满中部区域」
  （0.5–2.0 倍），删掉其中一部分内容后剩下的会自动放大补位
- 顶部图片区高度固定：相册里的竖图也只在这 648px 里排（`铺满` 裁切填满 / `原比例` 完整居中），
  **不会把句子顶下去**
- 浏览器 Canvas 完成，**模板图不上传**
- 个人信息卡片位置**自动识别**：近纯白二值化 + 连通域，取不接触画布边缘的最大白块；
  标准版只借用识别结果决定「从用户图里抠哪一块」，卡片自身位置与尺寸固定
- 中文逐字断行、英文按词断行，并避免行首出现 `，。、；：？！）】》」』` 等标点
- 正文 Inter + 苹方混排，卡片为圆角卡片

> **长版海报**（`?long=1`）保持原有版面：关键词大标题（Playfair Display 衬线）、标题分隔线、
> 毛玻璃单词卡片（左侧渐变竖条、等宽音标、词性彩色胶囊 n./v./adj.、例句引用块）、
> 按内容长高。本阶段未改动，后续再迭代。

**交互**

- **没有浮框、没有菜单、没有引导动画**：整页只有海报与顶栏四个按钮
- **单击顶部图片 / 信息卡 = 从手机相册选图**
- **双击日期 / 英文 / 中文 / 出处 = 从海报删除该元素**，其余内容自动放大补齐（不可逆，刷新恢复）
- **在句子上上下滑动 = 实时缩放中部字号**（上滑放大、下滑缩小）
- **长按海报 = 保存**（顶栏也有保存按钮）
- **顶栏「重新获取」= 回到初始状态**（等同重启 App：清隐藏、缩放归位、图片与比例复原）
- **刷新即初始**：换的图、删的元素、缩放都不记忆
- PWA，可添加到主屏幕；保存到相册

## 快速开始

```bash
cd app
node server.js            # 默认 http://localhost:8787
PORT=3000 node server.js  # 自定义端口
```

要求 **Node.js ≥ 18** —— 只用内置模块，无需 `npm install`。

打开页面后会依次调用 `/api/daily` 取内容、`/api/img` 代理下载配图，然后在浏览器端合成。

| 路径 | 说明 |
| --- | --- |
| `GET /api/daily` | 结构化今日内容（JSON），`?refresh=1` 跳过缓存；上游缺解析时附带 `missing` / `candidates` / `fallback` |
| `GET /api/lookup?word=<word>` | 查词典，补全音标 / 释义 / 双语例句（供「关键词补全」切换候选时调用） |
| `GET /api/img?u=<url>` | 图片代理，仅放行 `static.esdict.cn` 等白名单域名 |
| `GET /api/health` | 健康检查 |

### 调试参数

- `?raw=1` —— 只显示海报本身，便于导出 / 截图
- `?bg=natural|cover` —— 指定背景模式
- `?long=1` —— 长版海报（旧参数 `?ex=1` 同样生效）
- `?word=&en=&cn=&source=` —— 覆盖文案，便于排版测试
- `?ph=ˈɪmpʌls`（单音标）或 `?ph=英:ɪɡˈzæmpl|美:ɪɡˈzɑːmpl`（双音标）—— 覆盖音标，便于测试排版

## 部署

任意能跑 Node 的平台均可，只需一条启动命令：

```bash
node server.js          # 监听 process.env.PORT
```

无构建步骤、无 `node_modules`、无外部服务依赖。
