# 每日一句 · 海报生成器

把 [欧路词典「英语每日一句」](https://dict.eudic.net/home/dailysentence) 的当日内容，
和乐词 App 的「个人信息卡片」模板合成为一张竖版手机海报
（标准版 **1080 × 1920**，需要时自动加高）。

一句话概括：**打开网页 → 自动抓取今日金句 → 一键生成可发朋友圈的打卡长图**。

## 特性

**抓取**

- 中英文句子、关键词、音标（英式 / 美式双音标）、词性释义、例句、出处
- 音标先归一化再排版：剥掉数据源自带的外层斜杠 / 方括号，统一印成
  `英 /dɪˈsiːv/　美 /dɪˈsiːv/`（单音标不加语言标签），不会出现双份斜杠
- 网页「每日一句」卡片左上角的配图（`static.esdict.cn/MediaPool/daymonthimg/…`，每天轮换）
- 真人发音地址（正常 / 慢速，可试听）
- 去标签时区分内外联：`<span>`/`<a>`/`<b>` 这类内联标签直接删掉、**不补空格**，
  只有 `</p>`/`<br>` 这类换行标签才换成一个空格 —— 上游会给关键词套高亮标签，
  一律换成空格会在中文里印出「我对他所说的感到 失望 。」这种多余空白

**上游缺内容时的兜底（2026-09-19 起）**

欧路偶尔会在「解析」区块整段漏发（只剩一段 CSS），此时页面**没有关键词、没有释义、没有例句**。
以前的做法是把句子里最长的词当关键词，猜出 `ourselves` 这种结果，再挂一张空卡片 —— 比不显示更误导。
现在的做法：

- **不猜词**：从英文句子按「闭类词黑名单 + 词频 + 词长」打分，给出 Top 3 候选关键词，默认选第一个
- **查词典补全**：拿候选词去 `dict.eudic.net/dicts/en/<word>` 取音标 / 释义 / 双语例句；
  查到「过去式 / 复数」这类词条时自动回查原形（`deceived` → `deceive`）
- **卡片圆标**：关键词 / 释义不是上游今天给的内容时，单词卡片**右下角**有一个很轻的加圈单字
  —— `补`（释义来自词典补全）或 `选`（只是自动选词，没查到释义）
- **改词自动重查**：在「文案」里改关键词，稍停一下就会自动重查词典并换掉音标 / 释义 / 例句，
  不会留下上一个词的内容；若你自己手写过释义，则不覆盖（只清掉属于旧词的音标与例句）
- **该藏就藏**：连候选都没有时**不画单词卡片**，版面自动收紧，只留句子与信息卡
- **可人工切换**：页面多出一块「关键词补全」，点其它候选即可重新查词回填
- 上游正常出数据的日子，以上逻辑完全不触发，也不会多发一个请求

> 词典页会把释义里随机的汉字换成小图（`<img class="dictimgtoword">`），单次抓取常常缺字。
> 所以这里用「多次抓取 + 逐位合并」把缺字补回来；再叠加长连接复用与串行节流，
> 因为上游在高频请求下会 302 到登录页。
>
> 有一小部分替换是**按字固定**的（图名就是那个字的指纹，整页同一个字永远缺），
> 重试再多也补不回来。这类残留缺字**不再硬删**：含缺字的义项整条不显示、
> 含缺字的例句整条丢掉 —— 宁可少一条，也不在海报上印「寂的」这种残词。
> 义项被剔完就当作「没查到」，退回只放关键词。

**合成**（标准版，默认）

- 版面**三段式**，从上到下：**顶部图片区**（固定 648px 高）→
  **中部句子区**（日期胶囊靠右，英文 + 中文 + 出处作为一个整体居中）→
  **个人信息卡**（距左 / 右 / 底三边等距 48px）
- 画布**恒 1080×1920（9:16）**，手机与桌面同一条路径：宽度充满、竖直居中，上下留底色块，
  屏幕上看到的就是长按另存的那张图；文字字号是**固定设计基准**（日期 28、英文 50 / 中文 44、
  出处 36），进入就按它显示、**不再自动放大铺满**，只有整块装不下中部区域时才整块等比缩小保底
- **四套配色主题**（2026-09-24 定稿）：墨蓝夜空（默认，冷暗）/ 暖纸墨字（暖浅，深墨字，白天可读）/
  绛红夜（暖暗，玫瑰金点缀）/ 青瓷浅冷（冷浅，墨青字）—— 摇一摇循环切换，
  整张海报（背景 / 文字 / 卡片 / 强调色）随主题走，另存的图就是当前配色；
  选择按设备记住（`?theme=` 可当次预览）
- **海报四角是圆角（32 设计值）**，而且是**画进成品**的：长按另存的 PNG 自己就是一张圆角卡片
  （四角透明，贴到聊天 / 文档里正好是一张圆角卡片），屏幕上用**同一半径**显示 ——
  所以「屏幕上看到的 = 长按另存的」依然成立
- 竖直方向的「居中」指**对整块物理屏居中**：加到主屏的独立应用形态下，系统给的布局框比屏幕
  **矮一个状态栏**，所以在框里居中会整体偏上半个状态栏（照片压刘海、底部多一截黑）。
  独立形态下会按「物理屏高 − 布局框高」补一个上边距，把它拉回整屏居中 ——
  与 iPhone 自己显示同一张 1080×1920 的位置一致；**手机浏览器 / 桌面浏览器里不做这个补正**
- 顶部图片**按宽度铺满 1080、高度按原始比例，超出 648px 的部分裁掉**：
  竖图只显示最上面一段，宽图下方露出一段底色 —— 图片永远不会溢出去盖住中部句子
- 浏览器 Canvas 完成，**模板图不上传**
- 个人信息卡片位置**自动识别**：近纯白二值化 + 连通域，取不接触画布边缘的最大白块；
  标准版只借用识别结果决定「从用户图里抠哪一块」，卡片自身位置与尺寸固定
- 中文逐字断行、英文按词断行，并避免行首出现 `，。、；：？！）】》」』` 等标点
- 英文句用 **EB Garamond**（OFL 免费字体、自托管），正文 Inter + 苹方混排，卡片为圆角卡片

> **长版海报**（`?long=1` 或双指扩）：关键词大标题（Playfair Display 衬线）、标题分隔线、
> 毛玻璃单词卡片（左侧渐变竖条、等宽音标、词性彩色胶囊 n./v./adj.）、按内容长高。
> **交互与配色同标准版全量**（2026-09-24 迁移：朗读 / 日期切换 / 双击删除 / 字号缩放 /
> 信息卡换图 / 下拉更新 / 主题 / 摇一摇）；例句引用块已整体移除；
> 版式按设备记住，URL `?long=1` 可强制指定。

**交互**

**界面上一个按钮都没有** —— 整屏只有海报，功能全部由手势承载（首次进入有一行 3 秒后消失的提示）：

| 手势 | 作用 |
| --- | --- |
| 长按任意位置 | 保存（iOS 弹浮层：长按图片 → 存储到照片；桌面 / Android 直接下载） |
| 单击顶部图片 / 信息卡 | 从手机相册选图（零延迟；这两块不定义双击） |
| 单击英文句 | 朗读，并在英文句上升起**只有竖条的波形**（无底板、比文字窄一档；等 300ms 确认不是双击） |
| 单击中文句 / 出处 | **不发音**（单击只为区分双击，双击仍是删除） |
| 单击日期胶囊 | 今日 ⇄ 昨日存档切换 |
| 双击日期 / 英文 / 中文 / 出处 | 从海报删除该元素，其余内容重新居中（**不再自动放大补位**；不可逆，刷新恢复） |
| 在文字区（2 日期 / 3 英文 / 4 中文 / 5 出处）上上下拖动 | 实时缩放该区字号（上滑放大、下滑缩小；**2 区能放到 3 倍、3/4/5 区到 1.6 倍**；**3/4/5 联动、2 区独立**） |
| 非句子区向下拉 ≥90px | 回到初始状态（等同重启 App：清隐藏、缩放归位、图片复原） |
| **双指扩 / 双指捏**（海报上） | 扩 = 标准版 → 长版海报；捏 = 长版 → 标准版。toast 报版式，选择按设备记住（**只在空闲态生效**：播放 / 换图调整中不响应） |
| **摇一摇手机** | 在四套配色之间循环切换（墨蓝夜空 → 暖纸墨字 → 绛红夜 → 青瓷浅冷），toast 报主题名；选择按设备记住，换的配色也会印进长按另存的图。iOS 第一次点海报时会请求「动作与健身」权限（摇一摇必需），拒绝则不影响其它功能 |
| **换图后**：单指拖动 / 双指捏合 / 点窗口 / 点窗口外 | **弹出整屏调整层**（海报不动）—— 层里只有居中的换图区与这张图：窗口内清晰、窗口外是同一张图压暗后的其余部分（拖动 / 缩放的引导）；单指挪图、双指缩放、点窗口换同一张、点窗口外即完成（保存 / 更新 / 朗读 / 删除全部让路） |

- **刷新即初始**：换的图、删的元素、缩放都不记忆
- 顶部图片按**宽度铺满 + 超出裁切**：竖图只显示最上面一段，宽图下方露底色，图片永不盖住中部句子
- PWA，可添加到主屏幕；保存到相册

## 快速开始

```bash
cd app
node server.js            # 默认 http://localhost:8787
PORT=3000 node server.js  # 自定义端口
```

要求 **Node.js ≥ 18** —— 只用内置模块，无需 `npm install`。

打开页面后会依次调用 `/api/daily` 取内容、`/api/img` 代理下载配图，然后在浏览器端合成。

| 路径 | 说明 |
| --- | --- |
| `GET /api/daily` | 结构化今日内容（JSON），`?refresh=1` 跳过缓存；上游缺解析时附带 `missing` / `candidates` / `fallback` |
| `GET /api/lookup?word=<word>` | 查词典，补全音标 / 释义 / 双语例句（供「关键词补全」切换候选时调用） |
| `GET /api/img?u=<url>` | 图片代理，仅放行 `static.esdict.cn` 等白名单域名 |
| `GET /api/health` | 健康检查 |

### 调试参数

- `?raw=1` —— 只显示海报本身，便于导出 / 截图
- `?theme=night|paper|ember|celadon` —— 预览指定配色（**只当次生效、不写记忆**；桌面没有加速度计，
  这是预览四主题的方式）
- `?bg=natural|cover` —— 指定背景模式
- `?long=1` —— 长版海报（旧参数 `?ex=1` 同样生效；**强制指定**，优先于版式记忆）
- `?word=&en=&cn=&source=` —— 覆盖文案，便于排版测试
- `?ph=ˈɪmpʌls`（单音标）或 `?ph=英:ɪɡˈzæmpl|美:ɪɡˈzɑːmpl`（双音标）—— 覆盖音标，便于测试排版
- `?fit=device` —— 画布自适应（默认关；开启后按设备分辨率出图，框架保留备用）
- `?diag=1` —— 真机诊断页：页面顶部叠一段**纯文本**关键数字（是否装到主屏 / 屏幕与安全区 /
  舞台补正 / 海报尺寸与圆角 / 版面与字号 / 语音自证），**长按面板 → 全选 → 拷贝**就能贴回来报问题，
  不必截图。平时不带这个参数时它完全不存在；这个模式下长按不会保存海报（长按让给系统菜单）

**报问题只要一句话**（区域编号 + 现象 + 期望，例「3 区波形左右不匀，左边空得多，希望两边一样」）：
量测由 `node app/measure.js` 完成（默认不出图，`--checks` 给逐条 PASS/FAIL，`--crop <编号>` 才出
那一块的局部放大图）；只有 iOS 专属问题才需要在手机上读 `?diag=1` 的文本。

## 部署

任意能跑 Node 的平台均可，只需一条启动命令：

```bash
node server.js          # 监听 process.env.PORT
```

无构建步骤、无 `node_modules`、无外部服务依赖。
